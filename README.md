Интерактивный 3D-симулятор рабочего места диспетчера атомной электростанции. 
Проект выполнен в рамках курсовой работы по учебному предмету «Основы алгоритмизации и программирования».

## 📌 Описание проекта

Приложение моделирует процесс управления энергоблоком АЭС. Игроку необходимо поддерживать стабильную частоту сети (50 Гц), балансируя между мощностью ядерного реактора, потреблением городов и работой гидроаккумулирующей станции (ГАЭС).

**Основные возможности:**
- Управление мощностью реактора (с учётом инерции).
- Управление режимами ГАЭС (турбина / насос).
- Динамическая модель суточного потребления электроэнергии.
- Система случайных событий (жара, аварии ЛЭП, техобслуживание и др.).
- Интерактивные 3D-кнопки и монитор с показателями в реальном времени.

## 🛠 Технологии

*   **Язык программирования:** C++17
*   **Графическая библиотека:** Raylib 5.0
*   **Среда разработки:** Microsoft Visual Studio 2022

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `W` `A` `S` `D` | Перемещение камеры по комнате |
| `ПКМ + мышь` | Вращение камеры |
| `E` или `ЛКМ` | Нажать на 3D-кнопку под курсором |
| `↑` / `↓` | Увеличить / уменьшить мощность реактора (вручную) |
| `1` / `2` / `3` | Режим турбины / насоса / останов ГАЭС |
| `T` | Переключить режим обучения (без штрафов) |
| `ESC` | Выход в главное меню |

## 🚀 Как запустить

1. Скачайте последний **Release** (или папку с проектом).
2. Убедитесь, что файлы ресурсов (`for_kyrsovoi`, шрифт `Cousine-Regular.ttf`) находятся в одной папке с исполняемым файлом.
3. Запустите `Simulator.exe`.

*(Для сборки из исходников: откройте `Simulator.sln` в Visual Studio, убедитесь, что библиотека Raylib подключена, и нажмите F5).*
